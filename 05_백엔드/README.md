# 백엔드 자료

Node.js 와 Express 로 **서버를 처음부터 만드는** 교재입니다.
12단원 · 155파일 · 약 35,700줄.

프로그래밍이 처음은 아니지만 **백엔드는 처음인** 사람을 대상으로 합니다.
JS 기초(변수·함수·배열·객체·비동기·DOM)를 알고 있다고 보고 시작합니다.

---

## 시작하기

```bash
cd 백엔드자료
npm install          # 한 번만
node 01_Node_시작하기/개념01_Node란_무엇인가.js
```

패키지는 **맨 위 폴더에 한 번만** 설치합니다.
Node 가 `node_modules` 를 위쪽으로 거슬러 올라가며 찾기 때문에,
단원 폴더 안에서 실행해도 잘 찾습니다.

| 도구 | 왜 |
| --- | --- |
| Node 18 이상 | `fetch` 가 내장돼 있어야 합니다 (24 권장) |
| VS Code | 아무 에디터나 됩니다 |
| **Postman** | 03단원부터 필수입니다. 브라우저로는 POST 를 못 보냅니다 |
| 크롬 | 08·10단원에서 F12 를 계속 씁니다 |

### 왜 00단원이 먼저인가

코드부터 시작하면 "이 기능이 왜 필요하지?" 를 스스로 답할 수 없습니다.

00단원은 **Node 기능을 안 씁니다.** 순수 JS 배열·객체만으로 돌아갑니다.
(`require`·`fs` 는 01·02단원에서 배웁니다.)
대신 이런 걸 정합니다.

- 현장 문서가 어떻게 생겼나 (표형 · 서식형 · 덧붙임형)
- ★ 어떤 값이 **밖으로 나가면 안 되나** (이름·사번·연락처)
- ★★ AI 에게 **시키면 안 되는 것**은 무엇인가 (세기·판정·실행·법적 판단)

`data/샘플문서/` 에 실제 모양의 현장 문서 여섯 개가 들어 있습니다.
**이 단원에서 직접 열어 봅니다.** 코드로 읽는 게 아니라 에디터로 엽니다.
점검일지·작업표준서·설비이력카드·불량보고서·자재출납대장·MSDS 여섯 가지가,
뒤에서 계속 이야기하게 될 **문서의 실물**입니다.

### 왜 03단원에서 맨손으로 만드나

Express 를 바로 배우면 "왜 이렇게 쓰는지" 를 모릅니다.
`if` 를 서른 개 쓰고 `writeHead` 를 반복해 본 사람만
04단원에서 `app.get` 이 왜 고마운지 압니다.

### 왜 07단원에서 파일로 저장하나

데이터베이스는 PART 4 입니다.
그 전에 **왜 데이터베이스가 필요한지** 를 손으로 겪습니다.
07단원에서 20건을 동시에 저장하면 19건이 사라지는 것을 직접 재 봅니다.

## 이 자료의 약속

### 적힌 출력은 전부 진짜입니다

```js
console.log(1 + 2);
// 출력: 3
```

이 주석은 손으로 적은 것이 아니라 **기계로 대조한 것**입니다.
서버 자료도 마찬가지입니다.

```js
// 확인: GET /health
// 응답: 200 {"status":"ok"}
```

이건 진짜로 서버를 띄워 요청을 보내고 응답을 맞춰 본 것입니다.
화면도 진짜 크롬으로 버튼을 눌러 확인했습니다.

> **결과가 다르면 여러분이 틀린 것입니다.** 자료를 의심하지 말고 코드를 보세요.
> 그래도 다르면 알려 주세요. 자료가 틀렸을 수 있습니다.

### 틀린 예를 일부러 넣어 뒀습니다

`자주 하는 실수` 절에 있는 것들은 대부분 **자료를 만들면서 실제로 겪은** 것입니다.
`✏️ 직접 해보기` 에 "일부러 망가뜨려 보세요" 가 자주 나옵니다. 꼭 해 보세요.
**확인한 뒤에는 반드시 되돌리세요.**

### 한글은 값에만 씁니다

이 자료가 계속 강조하는 규칙입니다.

| 곳 | 한글 | 안 쓰면 무슨 일이 |
| --- | --- | --- |
| 라우트 주소 | ✗ | 에러 없이 조용히 404 |
| 응답 헤더 값 | ✗ | 500 으로 터짐 |
| 요청 헤더 값 | ✗ | 요청이 아예 안 나감 |
| 업로드 필드 이름 | ✗ | `Unexpected field` |
| 업로드 파일 이름 | △ | 깨져서 도착 (되돌려야 함) |
| 쿼리·경로·본문·응답 | ○ | — |

안 되는 것은 전부 **헤더에 실려 가는 것**입니다.
HTTP 헤더는 아주 오래된 약속이라 영어와 숫자만 담깁니다.
