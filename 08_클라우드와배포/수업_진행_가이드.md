물어볼 순서를 정해 두세요.

3. Network 에서 API 주소가 localhost 인가 (17·18번)
4. 시크릿 창에서도 그런가 (아니면 19번, 캐시)

★ 4번이 제일 빠른 판별입니다. 시크릿 창에서 잘 되면 캐시 문제입니다.

## 11단원(로그인) 강사 노트

이 단원은 **PART 3 05단원 개념03 이 남긴 약속을 갚는 자리**입니다.
그 파일을 열어서 "진짜 로그인은 PART 4 에서 배웁니다" 줄을 먼저 보여 주고 시작하세요.
학생이 "아 그때 그거" 라고 하면 절반은 된 것입니다.

**꼭 짚을 것 세 가지**

| 무엇 | 왜 |
| --- | --- |
| 토큰은 암호가 아니다 | 제일 많이 오해합니다. jwt.io 에 붙여 넣어 직접 보게 하세요 |
| 서명 → 내용 순서 | 순서를 바꾸면 alg:none 이 통과합니다. 개념03 의 7-3 |
| IDOR (개념04 의 7번) | 로그인만 확인하고 "내 것인가" 를 안 보는 실수. 실무에서 제일 흔합니다 |

**시연하면 좋은 것**

개념03 을 돌린 뒤 토큰을 복사해 <https://jwt.io> 에 붙여 넣으세요.
비밀키 없이 내용이 그대로 보입니다. 말로 열 번 하는 것보다 낫습니다.

**학생이 자주 하는 질문**

- "그럼 토큰을 암호화하면 되지 않나요"
  → 됩니다(JWE). 그런데 그러면 서버가 매번 풀어야 하고, 애초에 넣지 않으면 될 일입니다.
- "왜 라이브러리를 안 쓰나요"
  → 개념05 의 9번에 답이 있습니다. 진짜로는 씁니다. 고르려면 알아야 해서 만들어 본 것입니다.
- "로그아웃했는데 왜 15분 동안 되나요"
  → 개념05 의 7번. 그 15분이 싫으면 세션(개념03 의 방법 A)으로 돌아가야 합니다.

개념05 의 6번(리프레시 회전)과 연습문제 14번을 빼세요.
개념01~04 까지만 해도 "직접 만든 로그인" 은 완성됩니다.
